# River Route

[![PyPI version](https://badge.fury.io/py/river-route.svg)](https://pypi.org/project/river-route/)

`river-route` is a Python package for routing runoff and discharge through large river networks. The routing kernel is
Muskingum with static parameters, with valid configuration options enforced everywhere possible. Tutorials, the config
file reference, the file schemas, and the math are in the documentation at
[river-route.code.hales.app](https://river-route.code.hales.app).
